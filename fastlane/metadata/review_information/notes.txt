2. PURPOSE AND AUDIENCE
PDFLito is a document scanner for private users and small offices in German-speaking countries who want to file paper documents (invoices, letters, contracts) as small, searchable PDFs. It solves two common problems of scanner apps: blurry scans that are noticed too late, and files with meaningless names. PDFLito checks every page for sharpness on the device, asks the user to rescan unreadable pages, reads the document heading and suggests a file name such as "2026-10-31 Rechnung Stadtwerke".

3. HOW TO USE THE MAIN FEATURES
No login and no sample files are needed; any printed page works.
- Tap "Scannen" and hold the iPhone over a printed page. The camera releases the shutter by itself once the page is fully visible, the phone is held still and the picture is in focus. A manual shutter button is also available. Tap "Fertig".
- "Prüfen & speichern": every page shows a status ("Gut lesbar", "Unscharf" ...). Tap a page to view it enlarged. Blurry pages are excluded until rescanned ("Neu scannen") or kept on purpose ("Trotzdem verwenden"). The file name is pre-filled from the document heading and can be edited. Choose colour, greyscale or black-and-white.
- Tap "Speichern". The PDF appears in the document list; tap it to open, swipe to share, rename or delete.
- Settings (gear icon): storage location (inside the app, a location chosen in the system save dialog on each save, or a fixed folder chosen with the system Files picker), camera mode, file name format, compression, strictness of the sharpness check.

4. EXTERNAL SERVICES
None. PDFLito uses only Apple frameworks on the device (AVFoundation, Vision, VisionKit, Core Image, PDFKit). It makes no network connections, uses no analytics, advertising, authentication, payment or AI services and collects no data. Saving to iCloud Drive, Google Drive or similar happens only through the system Files picker and share sheet, if the user chooses such a location.
